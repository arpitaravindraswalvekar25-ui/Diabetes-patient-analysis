Diabetes Patient Analysis

📌 Project Overview

This project focuses on analyzing diabetes patient data to identify important patient characteristics,
outcomes. The analysis was performed using Excel, SQL, and Power BI.

🎯 Objectives

- Analyze the demographic and clinical characteristics of the diabetes patient population. 
- Measure and compare HbA1c levels before and after treatment to quantify treatment outcomes. 
- Evaluate medication usage and adherence by comparing different therapies with patient HbA1c outcomes. 
- Identify patterns in HbA1c control, high-risk patients, geographic distribution, and common diabetes complications. 
- Generate actionable insights and recommendations from the analysis to support better diabetes management and decision-making.


🛠️ Tools & Technologies

- Microsoft Excel – Data cleaning and preliminary analysis
- SQL – Data querying and analysis
- Power BI – Interactive dashboard and data visualization
