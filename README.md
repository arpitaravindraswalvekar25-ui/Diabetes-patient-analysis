DIABETES PATIENT ANALYSIS
* PROJECT OVERVIEW
This project focuses on analysing diabetes patient ata to identify important patient characteristics,
and outcomes.The analysis was performed using Excel, SQL , and Power BI
* Objective:
Analyze the demographic and clinical characteristics of the diabetes patient population. 
Measure and compare HbA1c levels before and after treatment to quantify treatment outcomes. 
Evaluate medication usage and adherence by comparing different therapies with patient HbA1c outcomes. 
Identify patterns in HbA1c control, high-risk patients, geographic distribution,
and common diabetes complications. 
Generate actionable insights and recommendations from the analysis to 
support better diabetes management and decision-making.
* Tools and Technologies:
Microsoft Excel - Data cleaning and preliminary analysis
SQL - Data quering and analysis
Power BI - Interactive dashboard and data visualisation.
